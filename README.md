# 과학토론타이머

4팀 과학토론대회용 Electron 데스크탑 앱 (Windows / macOS).

원래 단일 HTML 파일이었던 토론대회 진행 타이머를 진행자 콘솔 + 발표용 시계 + PPT 위에 띄우는 팝업으로 분리해 데스크탑 앱으로 만든 버전.

## 주요 기능

### 3종 윈도우
| 윈도우 | 용도 |
|---|---|
| **콘솔** | 진행자용 컨트롤러. 현재/다음 단계, 작은 미리보기 타이머, 모든 버튼 |
| **시계** | 발표용 큰 디스플레이. 빔프로젝터로 옮긴 뒤 전체화면 (`F11`) |
| **팝업** | PPT/PDF 전체화면 위에도 뜨는 항상 위 미니창. 사이드에 배치 |

세 창은 콘솔의 상태와 실시간 동기화.

### 시간 제어
- ▶ 시작 / ⏸ 정지 / ↻ 초기화 / ⟲ 전체초기화
- ⏮ 이전 / ⏭ 다음 단계
- ⏩ **시간 감기**: −1분 / −10초 / +10초 / +1분
- 🔔 **종소리 테스트**: 30초 경고로 점프 / 종료음으로 점프 (5초 대기 후 자동 재생)

### 설정 (⚙ 설정 모달)
- **테마**: ☀ 라이트 · 🌙 다크 · 📜 세피아 · ⚓ 네이비
- **시나리오 편집**: 단계 추가/삭제, 단계명·상세·시간(MM:SS)·종류(발표/준비/질의응답/마무리) 직접 수정
- **종소리 프리셋**: 종(기본) · 차임 · 부저 · 종(저음) + 볼륨 슬라이더, 미리듣기
- **앱 제목**: 윈도우 타이틀바에 표시할 제목 변경

설정은 `localStorage`에 저장되어 재시작해도 유지.

### 기본 시나리오 (4팀, 25단계)
1. 자기주장 발표 (4팀 × 5분) + 사이 준비시간 (3분 × 3)
2. 전체 준비시간 11분
3. 질의응답 (각 팀 답변 × 3회 = 12라운드 × 5분)
4. 주장다지기 준비 10분
5. 주장다지기 (4팀 × 3분, 4→1 역순)

설정에서 자유롭게 수정 가능.

## 단축키

| 키 | 기능 |
|---|---|
| Space | 시작 / 정지 |
| ← / → | 이전 / 다음 단계 |
| R | 현재 단계 초기화 |
| F11 | 시계 창 전체화면 (메뉴) |
| Cmd/Ctrl+P | 팝업 토글 (메뉴) |
| Cmd/Ctrl+Shift+C | 시계 창 다시 열기 (메뉴) |

## 실행

```bash
npm install
npm start
```

## 빌드 (설치 파일)

```bash
npm run build:mac    # macOS DMG
npm run build:win    # Windows NSIS 설치 파일
```

결과물은 `dist/` 폴더에 생성.

## 파일 구조

```
debate-timer/
├── main.js          # Electron 메인 프로세스 (윈도우 생성·IPC)
├── preload.js       # contextBridge API
├── index.html       # 콘솔 UI + 설정 모달
├── clock.html       # 시계 윈도우
├── popup.html       # 팝업 윈도우 (▶ 버튼만)
├── renderer.js      # 콘솔 로직 (상태·타이머·종소리·설정)
├── clock.js         # 시계 렌더링
├── popup.js         # 팝업 렌더링
├── styles.css       # CSS 변수 기반 4 테마
└── package.json
```
